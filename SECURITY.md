# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 4.x     | Yes       |
| < 4.0   | No        |

## Reporting a Vulnerability

Please don't report security vulnerabilities through public GitHub issues.

Instead, report them privately through [GitHub](https://github.com/jurager/teams/security/advisories/new), or email Yuri Gerassimov at me@gerassimov.me.

Please include a description of the issue, the affected versions, and steps to reproduce it. You will get a response within 7 days. Once the issue is confirmed, a fix will be released as soon as possible and the vulnerability will be disclosed in a security advisory.
